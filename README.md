# 🌻 Para ti

Un pequeño juego de cumpleaños. Todo está en `index.html`: no hay que instalar nada y funciona en cualquier navegador, en el celular o en la computadora.

## 🔗 Link para abrir el juego

**https://claude.ai/artifact/XuVSHZUAmkmkTbap9Nbh22**

Se abre en cualquier navegador, también en el iPhone.

## Recorrido

1. **Píldoras**: la azul abre el camino. La roja muestra un mensaje y luego desaparece.
2. **Número 11**: un mensaje de cumpleaños y un acertijo. La respuesta es *Fernanda* (no importan las mayúsculas ni las tildes). Al acertar aparecen los números **11 · 20**.
3. **Número 26**: un ramo de girasoles y un recuadro para escribir el código completo **11-11-20-26**.
4. **Final**: la carta, el cupón para el plan que ella quiera (se puede guardar como imagen), el mensaje de despedida y una lluvia de girasoles.

## Cómo obtener el link (GitHub Pages)

1. En GitHub, abre el repositorio → **Settings** → **Pages**.
2. En *Build and deployment*, elige **Source: Deploy from a branch**.
3. Elige la rama donde esté `index.html` (por ejemplo `main`), la carpeta `/ (root)`, y presiona **Save**.
4. Espera 1 o 2 minutos. El link aparecerá arriba con este formato:
   `https://daniisuarez95.github.io/C-digos-de-prueba/`
